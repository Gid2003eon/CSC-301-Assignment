# CSC 301 – Data Structures Assignment

## Overview

This repository contains practical implementations of fundamental data structures using Python as part of the CSC 301 Data Structures course.

The assignment demonstrates the understanding and application of arrays, stacks, and queues through interactive Python programs.

## Programming Language

Python 3

## Project Contents

### 1. Array Operations
Implementation of the following array operations:
- Insertion
- Deletion
- Searching
- Sorting using Bubble Sort
- Displaying array elements

### 2. Stack Implementation
A stack implemented using Python lists, following the LIFO (Last In, First Out) principle.

Operations include:
- Push
- Pop
- Peek
- Display
- Check if Empty
- Check if Full

### 3. Queue Implementation
A circular queue implemented using a fixed-size Python array, following the FIFO (First In, First Out) principle.

Operations include:
- Enqueue
- Dequeue
- View Front
- View Rear
- Display
- Check if Empty
- Check if Full

## How to Run

Ensure Python 3 is installed on your computer.

Navigate to the appropriate project directory and run the corresponding program.

Example:

```bash
python array_operations.py
```

For the stack:

```bash
python stack.py
```

For the queue:

```bash
python queue.py
```

## Purpose

The purpose of this assignment is to demonstrate practical knowledge of fundamental data structures and their applicable operations using Python.
